# Battery Atlas — сайт сбора сведений

Сайт для новой редакции ASUS Battery Limiter. Размещён в `docs/`, может публиковаться через GitHub Pages без сборки, сервера и зависимостей.

## Публикация

GitHub → Settings → Pages → Build and deployment → Deploy from a branch → `main` / `docs` → Save. Ожидаемый адрес после включения Pages: `https://egorkara.github.io/asus-battery-limiter/`. Наличие действующей публикации проверяется отдельно.

Для локального просмотра из корня репозитория: `python3 -m http.server 8000 --directory docs`, затем `http://localhost:8000/`. При открытии файла напрямую через `file://` браузер может блокировать загрузку JSON.

## Схема данных

- `data/catalog.json`: единый публичный каталог, `schema_version: 1`.
- `devices[]`: аппаратные отчёты о конкретном ноутбуке и батарее, отдельные `end_threshold`, `start_threshold`, `pause_charging`.
- `recommended_window`: `min_percent` и `max_percent` равны `null`, пока точная модель/ревизия батареи и источник не подтверждены.
- `manufacturer_guidance[]`: общие заводские режимы. **Не превращать** их автоматически в индивидуальные диапазоны.
- `evidence`: ссылка, дата проверки источника, тип свидетельства. `project_readme` означает заявленную в README совместимость, не независимое измерение.
- `policy`: предостережения для клиента; сам сайт не меняет параметры ноутбука.

Использовать профиль для управления зарядкой можно только после проверки точного соответствия модели/ревизии батареи, возможности аппаратного управления и доверенного источника диапазона. Фактическое состояние аккумулятора (ёмкость и циклы) утилита должна читать локально. Готовых точных диапазонов при создании сайта нет; ни один не выдуман.

## Приём новых данных

Форма создаёт черновик **новой задачи GitHub Issues** с JSON-отчётом. Предложенные MIN и MAX допускаются только парой и со ссылкой на источник; до проверки они всегда имеют статус `unverified_suggestion`. Пользователь отправляет её со своей учётной записи. Сайт ничего не сохраняет в браузере и не передаёт данные отдельному серверу. Сообщение **не** попадает в рабочий каталог автоматически: сведения проверяются, идентификаторы исключаются и изменения вносятся в JSON через обычный Git-коммит.

Сообщения GitHub публичные. Не принимать серийные номера, контакты, IP, MAC, домашние пути, полные дампы sysfs или персональные сведения. Поля `energy_full_uwh` и `energy_full_design_uwh` — в мкВт·ч; не смешивать их с `charge_full` в мкА·ч.

## Контроль

Проверка структуры и правил допуска: `python3 tests/check_catalog.py`. Форма не создаёт файл данных без проверки; сведения из чужих задач являются неподтверждёнными.
