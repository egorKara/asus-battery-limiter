ДОКУМЕНТАЦИЯ

Что действительно рекомендуют производители

Заводские режимы — это подтверждённые верхние ограничения, а не готовый индивидуальный диапазон MIN–MAX. Их нельзя автоматически назначать всем батареям одной марки.

Проверяемость важнее количества

Неизвестный минимум, непроверенная химия или отсутствие управления зарядкой остаются «неизвестно». Сайт не подменяет это придуманными значениями.

СТРУКТУРА ДАННЫХ

Один каталог. Прозрачные решения.

JSON хранится в том же репозитории, что и утилита. Каждая рекомендация сопровождается областью применимости, источником и датой проверки.

01
Точное соответствие

Диапазон для конкретной версии батареи нельзя выводить только из марки ноутбука.

02
Состояние — локально

Актуальные ёмкость и циклы утилита должна читать на устройстве. Публичные наблюдения не являются настройками пользователя.

03
Безопасное применение

Неизвестная возможность управления не считается поддерживаемой. Сайт не отправляет команды на ноутбук.
